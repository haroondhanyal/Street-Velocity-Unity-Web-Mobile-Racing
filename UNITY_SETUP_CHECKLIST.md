# Unity Setup Checklist

Native Android/iOS source is in [`Mobile_Game/Assets/`](Mobile_Game/Assets/). The independent responsive browser edition is in [`Web_Game/`](Web_Game/).

## Create and run the scenes

1. Open a Unity 2022.3 LTS or newer project.
2. Copy `Mobile_Game/Assets/` into the Unity project root and let Unity import the artwork and compile scripts.
3. Choose **Street Velocity > Phase 1 > Setup Foundation**. This generates Boot, Main Menu, placeholder world scenes, the 22-screen navigation UI, and Build Settings entries.
4. Choose **Street Velocity > Phase 2 > Build Driving Test Scene**. This generates `09_DriveTest`, the neon street, primitive player coupe, camera, race manager, four ordered checkpoint gates, race HUD, results overlay, and touch controls.
5. Open `Assets/_StreetVelocity/Scenes/00_Boot.unity` and press Play. From Home select Career → Event → Race Start → Start Race. The one-lap race starts after a three-second countdown; cross all four checkpoint gates in order to finish.
6. On finish, review race time, best time, credits, XP, level, and wallet. Choose **RACE AGAIN** to reload the test event or **GARAGE** to return to the 22-screen menu.

## Controls

- Keyboard: W/A/S/D or arrows to steer and accelerate, Space to brake/reverse, Left Shift to drift, N for nitro.
- Phone: on-screen left/right steering, throttle, brake, drift, and nitro buttons.
- Enable Unity's legacy Input Manager if keyboard controls are needed in the Editor.

## Build for Android/iOS

Set landscape orientation is done by Phase 1 setup. Install Android or iOS Build Support in Unity Hub, select the target in Build Settings, and configure signing/device options. Browser saves do not sync to Unity saves.

## Phase scope

Phase 1 and Phase 2 are generated by the Editor commands above. Phase 3 is integrated in the generated driving test scene. Native Unity currently includes one one-lap event and primitive geometry; Unity AI, multiple production tracks, traffic/police behavior, audio, final 3D car/world assets, and device QA are future Phase 4 work. The Unity Editor is required to compile scripts and generate scenes; generated scenes are not checked in.
